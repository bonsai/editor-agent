# 全国フリーペーパー／ZINE候補マップ

調査日: 2026-09-29

## 目的

Issue #2「ZINE・フリーペーパー編集者インタビュー」の候補媒体を全国から拾い、
**媒体 → 編集者 → 企画 → 素材 → 人選 → 判断 → 制約 → 結果**
を調査できる母集団を作る。

## 全国DB

- FURIPE: 日本全国のフリーペーパーを公式情報ベースで収録。2026-09-25時点で917媒体、うち566誌が発行中、553誌がWeb公開。
- FURIPE地域別掲載数: 東京157、神奈川78、大阪75、愛知71、北海道51、京都50、兵庫50、福岡50など。全国47都道府県をカバー。
- FURIPEジャンル: 地域・街、観光、食、子育て、学生、音楽、映画、アート、本・文学、ライフスタイル等。
- JNSCA: 全国の地域コンテンツ媒体を地域ブロック別に検索できる。2026年の新着媒体も確認可能。
- NDLのフリーペーパー調査ガイドも併用し、現行媒体だけでなく過去のタウン誌・フリーペーパーも母集団にする。

## インタビュー優先候補の選定軸

1. 編集長／発行責任者に直接アクセスできる
2. 創刊理由が明確
3. 少人数または独立系の編集体制
4. 紙とWebの両方を扱う
5. 地域・文化・サブカルなど編集判断が見えやすい
6. 企画、取材、人選、配布まで一貫して観察できる
7. 過去号を複数比較できる
8. 編集後記・創刊メッセージ・インタビュー等の一次情報が残っている

## 特に見るべき編集判断

- なぜこの媒体を始めたか
- 誰を読者として想定したか
- 「地域」をどう定義したか
- 何を載せないと決めているか
- 企画をどう選ぶか
- 人をどう見つけ、どう口説くか
- 写真・文章・デザインを誰が決めるか
- 広告と編集をどう分ける／接続するか
- 紙面制約を企画にどう変換するか
- 配布場所をどう選ぶか
- Web/SNSと紙の役割をどう分けるか
- 休刊・継続をどう判断するか

## 重要な観察

「フリーペーパー」だけでなく、ZINE／リトルプレス／ミニコミ／タウン誌まで含めると、
**大規模ネットワーク型 → 地域メディア型 → 独立系小規模出版 → 個人ZINE**
という編集環境の連続体を作れる。

Issue #2ではこの母集団から10媒体以上を詳細調査し、3〜5名の編集者をインタビュー候補に絞る。
