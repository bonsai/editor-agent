# 編集者のタイプ研究

> 目的: `editor-agent` の「編集長／オーケストレーター」設計に向けて、既存の編集者の役割を研究する。

## 1. NII / CiNii で確認できる編集者像

### 企画・出版プロデュース型

安原顕『「編集者」の仕事』は、編集者の仕事を「企画」まで遡って扱い、さらに出版プロデューサーへの転身まで含めている。CiNii Books の目次にも「『企画』とは何か」「出版プロデューサーへの転身」が確認できる。

- https://ci.nii.ac.jp/ncid/BA41210744

→ 編集者を「原稿を直す人」ではなく、**企画を発見し、作家・媒体・出版を動かす人**として捉える系統。

### 企画・読者・取材・構成型

『あなたも編集者』では、編集者を発行者・読者との関係で捉え、企画、取材、記事、価値判断、配列、レイアウトまで一連の仕事として扱っている。

- https://ci.nii.ac.jp/ncid/BN04230937

→ **読者を想定して素材を選び、構成し、価値判断する編集者**。

### ヒット企画・企画発見型

CiNii Research には『編集者72人が明かす これが私の「ヒット企画」』が登録されている。

- https://cir.nii.ac.jp/crid/1520010380218203008

→ 編集者の類型を「肩書」ではなく、**どんな企画を発見・成立させるか**から研究できる。

### 編集長・デスク／チーム推進型

新聞社の調査報道を対象にした研究では、デスクが取材のビジョンと目標を明確化し、取材班を編成し、記者の自律性を支援し、上司との議論を設けて組織内の説明責任を担うことが示されている。

- https://cir.nii.ac.jp/crid/1390852956486865024

→ **人を直接動かすだけでなく、目的・チーム・環境を設計して人が動ける状態を作る編集者**。

### 出版工程全体を設計する型

早稲田大学の出版デザイン研究では、広義の「Publishing Design」を企画、編集、制作、印刷、物流、購読者まで含む出版全工程として捉えている。

- https://waseda.repo.nii.ac.jp/record/21178/files/Honbun-4088.pdf

→ 編集を**コンテンツ単体ではなくシステム全体の設計**として捉える方向。

## 2. 現時点の編集者タイプ仮説

NII/CiNii の資料から、少なくとも次のタイプに分けられる。

| Type | 中心課題 | 主な仕事 |
|---|---|---|
| Acquisition / 企画発見型 | 何を作るか | 企画、著者発掘、市場探索 |
| Developmental / 構造編集型 | どう成立させるか | 構成、論旨、物語、素材整理 |
| Copy / Line / 文章編集型 | どう伝えるか | 文体、表現、正確性 |
| Managing / 進行管理型 | どう完成させるか | 工程、品質、予算、調整 |
| Desk / 編集長型 | 人をどう動かすか | ビジョン、編成、鼓舞、組織調整 |
| Producer / 全体設計型 | プロジェクトをどう成立させるか | 企画、資源、人、工程、出口 |
| Reader / 価値判断型 | 誰に何が届くか | 読者視点、選択、優先順位 |
| Connector / 接続型 | 何と何をつなぐか | 異分野、人、素材、文脈の接続 |

## 3. editor-agent との対応

既存の編集者論をそのままAI化するのではなく、これらを上位概念として統合する。

```
企画発見
   ↓
素材・人の発見
   ↓
意味・構造の編集
   ↓
人員・役割の編成
   ↓
工程・資源の管理
   ↓
専門Agentへの委任
   ↓
成果物の評価
   ↓
次の編集判断
```

ここで `editor-agent` は単なる Copy Editor ではない。

**Editor-in-Chief = Acquisition + Development + Desk + Producer + Conductor**

という仮説を置く。

## 4. 重要な研究上の発見

英語圏の出版実務では、commissioning/acquisitions、developmental、production、managing、copy などに役割分担される。一方、出版組織によっては一人が複数役割を兼ねる。

- Editors Canada: https://editors.ca/publications/professional-editorial-standards/fundamentals-editing/
- Penguin: https://www.penguin.co.uk/about/company-articles/job-roles-in-editorial

つまり「編集者」という一職種に見えて、実際には

**発見 → 判断 → 構造化 → 人間関係 → 進行 → 品質 → 出口**

という複数の機能の集合である。

`editor-agent` はこの機能集合をAgentとして再構成する。

- 映画監督

### 組織

- オーケストラ指揮者
- プロジェクトプロデューサー
- Creative Director
- Chief Editor

最終的には「編集者の職種分類」ではなく、

**どの判断をし、誰を動かし、何を接続し、どこまで責任を持つ人なのか**

という行動モデルに落とす。
